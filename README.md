Разработано мобильное приложение на платформе Android «Деканат».

Приложение реализует хранение данных в базе SQLite и выполнение запросов с выводом результатов в виде списков.
---
Реализованные объекты

- Faculty (Факультет)  
- StudentGroup (Группа)  a
- Student (Студент)  
- Exam (Экзамен)  
- Grade (Оценка)  
---
запросы

1. Список студентов заданного факультета  
2. Результаты экзаменов выбранного студента  
3. Список всех двоек за заданный период по выбранному факультету
