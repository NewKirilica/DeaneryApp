Тема:
Разработка системы напоминаний в Android-приложении с использованием NotificationManager

Описание выполненной работы:
В рамках индивидуальной практической работы было разработано Android-приложение для создания напоминаний о покупках. Приложение позволяет пользователю вводить название покупки, выбирать время отображения уведомления и получать системное уведомление Android в установленное время.

В процессе разработки были использованы:
- Android Studio;
- Java;
- XML;
- NotificationManager;
- AlarmManager;
- BroadcastReceiver.

Реализованные функции:
1. Переход к экрану создания напоминаний.
2. Ввод названия покупки.
3. Выбор времени уведомления.
4. Установка напоминания.
5. Отображение системного уведомления Android.
